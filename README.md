# Employee Database SQL Analysis

## 📌 Project Overview

This project focuses on analyzing a relational employee database using SQL.

The database contains information related to employees, departments, and projects. The project was created to practice SQL querying and extract meaningful information from relational data.

I independently solved 11 analytical SQL questions using different SQL concepts and techniques.

---

## 🎯 Project Objectives

The main objectives of this project were:

- Analyze employee-related information
- Work with data from multiple relational tables
- Retrieve and filter relevant records
- Perform aggregations and grouped analysis
- Compare information across departments
- Analyze employee and project-related data
- Practice advanced SQL techniques
- Organize query results into meaningful insights

---

## 🗃️ Database Structure

The analysis uses three main tables:

### Employee
Contains employee-related information.

### Department
Contains department-related information.

### Project
Contains project-related information.

These tables were used together to perform relational analysis using SQL JOINs.

## 📊 Analysis Performed

The project includes 11 analytical SQL questions covering different types of data analysis.

The queries were designed to practice:

1. Retrieving specific employee information
2. Filtering records based on conditions
3. Sorting and organizing query results
4. Performing aggregate calculations
5. Grouping employees for comparison
6. Filtering grouped results using `HAVING`
7. Combining information from multiple tables using `INNER JOIN`
8. Categorizing records using `CASE WHEN`
9. Using subqueries for deeper analysis
10. Using CTEs to structure complex queries
11. Applying window functions for analytical comparisons
